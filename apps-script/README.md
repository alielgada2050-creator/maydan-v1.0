# ميدان — Maydan

**منصة إدارة الفرق والمعدات والخدمات اللوجستية لمشاريع البنية التحتية**، تعمل بالكامل على خوادم Google: Apps Script للخادم، Google Sheets لقاعدة البيانات، Google Drive للمرفقات والنسخ الاحتياطية، وGmail للإشعارات ورموز الدخول.

## ما الذي يفعله

- **الدخول:** رقم الإقامة/الهوية ← رمز لمرة واحدة يصل على البريد (أو SMS عند تفعيل Twilio). أو الدخول بحساب Google داخل Google Workspace.
- **الفرق ومعداتها:** كل فرقة ← المراقب وسيارته (اللوحة، الحالة، غيار الزيت، الفحص) ← العمال والفنيون ← المعدات بسائقيها (JCB، ترنشر، بوبكات، بروش مكنسة، ديانا…).
- **الجاهزية تلقائياً:** الفرقة بلا معدة عاملة بسائق تظهر «متوقفة».
- **التعديل والنقل:** إضافة وتعديل كل بيانات الأفراد وأرقام جوالاتهم، والفرق، والمعدات. نقل فرد بين فرق، ونقل معدة **مع سائقها أو بدونه**، مع إشعار المراقبَين.
- **الطبقات:** المراقبون / سياراتهم / المعدات / السائقون / العمال، كل طبقة تُخفى وتظهر وحدها.
- **التواصل:** اتصال وواتساب وتيليجرام لكل فرد. **من لا يملك رقماً يتم التواصل معه عبر مراقبه.**
- **الخريطة والتنسيق:** مواقع الفرق الحية. عند طلب فرقة (مثال: فرقة الكهرباء GCB تطلب حفريات) يبحث النظام عن أقرب فرقة متاحة ضمن 1.5 كم، ثم يُشعر المهندس ومدير المشروع ومشرف المنصة بالبريد وداخل المنصة، ويمكن الإسناد بضغطة.
- **مشاركة الموقع الحي:** المراقب يفعّلها من جواله فيُرسل موقع فرقته كل دقيقة أثناء فتح التطبيق. أو يلصق رابط/إحداثيات Google Maps.
- **ترتيب الأعمال، المرفقات على Drive، سجل الدخول والتدقيق، نسخة احتياطية يومية، الوكيل الذكي** (OpenRouter / Groq / Gemini / DeepSeek مع تحويل تلقائي عند تعطل أحدها).

## الدخول في النسخة التجريبية

| الدور | الدخول |

| مدير مشروع | `2100000001` |
| مهندس | `2100000002` |
| مراقب فرقة X-03 | `2100000003` |

## النسخة النظيفة للموقع
1. ادخل كمشرف ← **الأفراد**: أضف المهندسين والمراقبين والعمال والسائقين بأرقام جوالاتهم.
2. **الفرق ومعداتها ← + فرقة جديدة**: اختر المراقب والمهندس.
3. أضف معدات كل فرقة وسائقيها، وسيارة كل مراقب.
4. **المستخدمون والصلاحيات**: أضف حساب دخول لكل مهندس ومراقب (رقم الإقامة + البريد)، واربط المراقب بسجله في «الأفراد» ليدير فرقته.

|---|---|
| مشرف المنصة | كل شيء + المستخدمون + الإعدادات + النسخ الاحتياطي |

## التكاملات الاختيارية (خصائص النص البرمجي)

| التكامل | الخصائص | ملاحظة |
|---|---|---|
| تيليجرام | `TELEGRAM_BOT_TOKEN` | أنشئ بوتاً من @BotFather، ثم ضع `telegramChatId` لكل مستخدم |
| SMS | `TWILIO_SID` `TWILIO_TOKEN` `TWILIO_FROM` | لإرسال رمز الدخول على الجوال. بدونه يُرسل على البريد |
| OpenRouter | `OPENROUTER_KEY` (`OPENROUTER_MODEL` اختياري) | نماذج مجانية؛ أسماؤها تتغير فحدّث الاسم عند الحاجة |
| Groq | `GROQ_KEY` (`GROQ_MODEL`) | طبقة مجانية |
| Gemini | `GEMINI_KEY` (`GEMINI_MODEL`) | من Google AI Studio |
| DeepSeek | `DEEPSEEK_KEY` (`DEEPSEEK_MODEL`) | منخفض التكلفة |

واتساب يعمل حالياً بروابط المحادثة المباشرة (wa.me). الإرسال الآلي عبر WhatsApp Cloud API يحتاج حساب Meta Business ويمكن إضافته لاحقاً.

## الأمان المطبّق
- لا كلمات مرور إطلاقاً: رمز لمرة واحدة مُجزّأ SHA-256، صالح 5 دقائق، 3 محاولات، إعادة إرسال بعد 60 ثانية، 3 رموز كحد أقصى كل 15 دقيقة.
- قفل 15 دقيقة بعد 5 محاولات خاطئة مع إشعار المشرف. لا يُكشف هل رقم الإقامة مسجّل.
- جلسة عشوائية 256-بت على الخادم، تنتهي بعد 30 دقيقة خمول، وتُحفظ في sessionStorage فقط (تنتهي بإغلاق التبويب).
- فحص الصلاحية والمدخلات على الخادم لكل عملية. الدوال الداخلية تنتهي بـ `_` فلا يمكن استدعاؤها من المتصفح.
- لا `innerHTML` لبيانات المستخدمين (حماية من XSS). منع حقن الصيغ في Sheets. أوراق قاعدة البيانات محمية: المالك فقط يعدّل مباشرة.
- المفاتيح في خصائص الخادم فقط ولا تصل للمتصفح. الوكيل الذكي لا يستلم أرقام الجوالات أو الإقامات.
- إقامات الأفراد مقنّعة لغير المشرف ومدير المشروع. سجل تدقيق لكل دخول وتعديل ونقل ورفض صلاحية.
- مكتبة الخرائط محمّلة مع تحقق السلامة (SRI)، والتطبيق محمي من التضمين في مواقع أخرى.

> **مهم:** كلمات المرور التي كانت مكتوبة في الملف القديم (`ali2030`، `asas2030`، `123456`) أصبحت مكشوفة. غيّرها في أي مكان آخر استُخدمت فيه.

## الحدود ومسار التوسع
- **حصة البريد اليومية:** حساب Gmail عادي نحو 100 رسالة يومياً، وGoogle Workspace نحو 1500. الحصة المتبقية تظهر في «الإعدادات». عند تجاوزها فعّل Twilio لرموز الدخول.
- **الدخول التلقائي بحساب Google** يعمل عند النشر داخل Google Workspace لنفس النطاق. لحسابات Gmail العادية استخدم رقم الإقامة والرمز.
- **السعة:** Google Sheets مناسب لعشرات الفرق ومئات الأفراد والمعدات وآلاف السجلات.
- **عند التوسع:** تبقى الواجهة كما هي (كل شيء يمر عبر `api(token, action, payload)`)، وتُستبدل طبقة `Db.gs` بـ Firestore أو Cloud SQL على Google Cloud، والخرائط بـ Google Maps Platform بمفتاح مقيّد بالنطاق.

## هيكل المستودع

```
src/                 الكود المصدري (يُرفع إلى Apps Script بـ clasp)
  Config.gs          الإعدادات والجداول
  Db.gs              طبقة Google Sheets (قفل، منع حقن الصيغ)
  Auth.gs            الدخول: إقامة + رمز / Google، الجلسات، القفل
  Api.gs             doGet + واجهة api() + الصلاحيات + التحقق
  Geo.gs             المسافات، الجاهزية، أقرب فرقة
  Notify.gs          بريد، تيليجرام، SMS
  Ai.gs              وسيط الذكاء الاصطناعي
  Setup.gs           الإعداد، البيانات التجريبية، النسخ الاحتياطي
  Index/Styles/App.html  الواجهة
paste/demo|clean     نسخ اللصق المبنية تلقائياً (npm run build)
tests/               محاكاة خدمات Google + اختبارات الخادم والواجهة
docs/GOOGLE_SETUP.md ربط Google والنشر
.github/workflows    CI للفحص + Deploy للنشر التلقائي
```

npm ci
