# ميدان — Maydan

منصة إدارة الفرق والمعدات والخدمات اللوجستية لمشاريع البنية التحتية (الشركة السعودية للكهرباء · شركة الأساس العريض · PDC).

| | |
|---|---|
| **الواجهة** | ملف HTML واحد (`public/index.html`) بلا مكتبات خارجية سوى Leaflet للخريطة (مع بصمة SRI) |
| **الخادم** | Node 22 بدون أُطر (`server/`) — يعمل على Google Cloud Run مع Firestore |
| **التشغيل المحلي** | افتح `public/index.html` مباشرة: يعمل محلياً ويحفظ على الجهاز |
| **التشغيل السحابي** | عند تقديم الصفحة من الخادم تتحول تلقائياً للوضع السحابي: دخول وOTP وتخزين وذكاء اصطناعي عبر الخادم |

## الميزات
- **الدخول:** رقم الإقامة/الهوية + كلمة مرور + رمز تحقق على الجوال أو البريد؛ قفل بعد 5 محاولات؛ جلسة 30 دقيقة خمول؛ اعتماد الحسابات من المشرف برمز تفعيل.
- **لوحة الأداء:** مؤشرات دائرية قابلة للتخصيص (الفرق العاملة، جاهزية المعدات، الصيانة، المستندات، الالتزام بالموعد، السلامة، إنجاز الأسبوع، اكتمال الربط) + إنتاجية كل فرقة + تنبيهات ذكية.
- **الهيكل الإلزامي والحصر:** المعدة/السيارة بسائقها ← المراقب ← المهندس ← المشروع ← الفرع، مع شاشة حصر وتصدير Excel للإدارة.
- **الصيانة الدورية:** الزيت، الفلاتر، الفرامل، الكفرات، البطارية، التشحيم، الصيانة الشاملة، الاستمارة — بالمسافة أو المدة، مع سجل الصيانة والعداد.
- **المعاملات:** أنواع أعمال (حفريات، تركيبات كهربائية، عدادات، فحص عدادات، فتح محطات) لكل منها إجراءاته وتقييم مخاطره؛ مكتبة إجراءات تُربط تلقائياً؛ استيراد معاملات من Excel مع تصنيف تلقائي أو بالذكاء الاصطناعي؛ مسح المستندات بالكاميرا.
- **نموذج فريق العمل:** يُولَّد تلقائياً عند إسناد المعاملة لفرقة: الأسماء وأرقام الإقامات والمهن من سجل الموظفين + تعميد الشركة السعودية للكهرباء + الشعارات، ثم محضر اجتماع ما قبل العمل — جاهزان للطباعة/PDF.
- **سجل الموظفين:** استيراد/تصدير Excel وCSV بصيغة Odoo `hr.employee`، وسحب مباشر من Odoo عبر الخادم.
- **الذكاء الاصطناعي:** OpenAI وGroq وOpenRouter وDeepSeek وGemini و9Router بترتيب احتياطي؛ تحليل أداء يومي/أسبوعي/شهري؛ مراجعة النواقص؛ تحليل محلي عند عدم توفر مزود.
- **الهوية:** الشعارات واسم الشركة ونصوص النماذج وصورة الهيدر قابلة للتغيير من الإعدادات (صورة افتراضية لأعمال الشبكات والكهرباء مع معدات السلامة).
- **اللغة والمظهر:** العربية والإنجليزية (اتجاه RTL/LTR تلقائي) ووضع داكن، ويُحفظ اختيار كل جهاز.
- **مرفقات الموظفين:** صورة الإقامة، كارت الأمن الصناعي، رخصة القيادة (للسائقين)، كارت التأمين — بتواريخ انتهاء وتنبيهات، ويظهر كارت الأمن في نموذج فريق العمل.
- **المشاريع والمراقبون:** إضافة وتعديل المشاريع والمهندسين والمراقبين وبياناتهم من شاشة الحصر أو من نموذج الفرقة مباشرة؛ أيقونات واتساب/تيليجرام بحجم الأيقونة مع الاسم داخل بيانات المهمة.
- **المرفقات على الخادم:** في وضع السحابة تُرفع الملفات إلى Cloud Storage (`FILES_BUCKET`) وتظهر لكل الأجهزة؛ محلياً تُحفظ في مجلد `data/files`.

## البدء السريع (محلياً)
```bash
npm ci
npm run build        # يبني public/index.html من src/
npm test             # اختبارات الخادم
npm run dev          # http://localhost:8080  (SETUP_TOKEN=local-setup-token-123 ، الرمز يظهر على الشاشة)
```

## هيكل المستودع
```
src/            مصدر الواجهة (app.js + index.src.html + الشعارات)
public/         الملف المبني index.html (يُولَّد بـ scripts/build.py)
server/         الخادم: index.js (API) · store.js (Firestore/ملفات) · integrations.js (OTP/AI/Odoo) · test/
scripts/        build.py وسكربتات التطوير
docs/           النشر، Odoo، واجهة API
.github/        CI، النشر على Cloud Run، المراجعة الأمنية الآلية
```

> **تنبيه:** لا ترفع ملفات الموظفين (`hr.employee*.xlsx`) ولا أي نسخة خاصة من المنصة إلى GitHub. هي مستثناة في `.gitignore`.
